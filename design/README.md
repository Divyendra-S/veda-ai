# Design exports

Drop the Figma frames here as PNG. I read these directly to build Phase 1.

Please export at **2x**, one file per frame:

| Filename | Frame |
|---|---|
| `01-upload.png` | Upload page — sidebar expanded, both upload cards |
| `02-upload-collapsed.png` | Same page with the sidebar collapsed (if the design shows it) |
| `03-processing.png` | The "Extracting… this may take a while" loading state |
| `04-review.png` | Question ↔ answer mapping page |
| `05-review-selected.png` | Review page with a question selected and its answer highlighted |

Anything else that exists in the file is welcome too — empty states, hover states,
error states, a color/type style sheet.

If Figma's Dev Mode is available to you, a screenshot of the color and text styles panel
saves me from eyedropping hex values off the PNGs.
